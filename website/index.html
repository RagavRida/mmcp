The Problem
AI agents are powerful alone.
Useless together.
Every agent framework builds agents that work in isolation. When agent A needs help from agent B, there's no standard way to share context, transfer state, or even discover that B exists.

What MMCP Does
Three primitives. Any framework.
Works with LangChain, CrewAI, AutoGen, or your custom agents. Drop-in, not rip-and-replace.
🧠

Shared Memory

Agents read and write shared context in real-time. TTL support. Versioning. Any agent sees what any other agent wrote.

🤝

Handoff

Transfer a full conversation — messages, context, shared memory snapshot — from agent A to agent B. Zero information lost.

🔍

Discovery

"I need debugging." MMCP finds the best agent by capability match + performance history. No hardcoded routing.

🎯

Domain-Aware Routing

Learns per-domain which model wins. Routes code to GPT-4o, math to DeepSeek, writing to Claude. Automatically.

📈

Skill Evolution

Agents learn new skills from outcomes. Lose skills after consistent failure. The system adapts without manual config.

✅

Multi-Verifier Voting

N critics vote on every output. Majority, unanimous, or weighted consensus. Catch errors before they cascade.

How It Works
Register. Discover. Hand off.
Three lines to make any agent collaborative.
import { AgentCoordinator } from "mmcp-core"; const coord = new AgentCoordinator(); // Register agents with capabilities const support = coord.register({ name: "Support Agent", capabilities: ["customer_support", "billing"], handler: supportHandler, }); const billing = coord.register({ name: "Billing Expert", capabilities: ["billing", "invoices"], handler: billingHandler, }); // Share context between agents coord.write(support, "user_intent", "billing question"); coord.write(support, "user_tier", "enterprise"); // Hand off — full conversation + shared memory transferred const result = await coord.handoff({ from_agent: support, to_agent: billing, messages: conversation, reason: "billing_request", }); // Billing agent sees everything. Zero information lost.
